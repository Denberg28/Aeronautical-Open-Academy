# Drone 0 to Hero — Practical UAV Crash Course

**Course:** UAV-101 | **Duration:** 40 hours / 5 days | **Edition:** 2026

A skills-first introduction to safe multirotor UAV operations. The learning sequence is **Demonstrate → Practice → Challenge → Evaluate → Advance**.

## Course materials
- [Training Modules — Learner Edition (PDF)](Drone_Zero_to_Hero_Training_Modules_2026_LEARNER.pdf) — 60 pages: presentation outlines, hands-on activities, practical assessments, checks and reference material. Instructor-only answer keys are **not included**.
- [Classroom Presentation (PDF)](Drone_Zero_to_Hero_Classroom_Presentation_2026.pdf) — 62 pages: 60 teaching slides plus opening and closing slides.

## Modules
1. Safety before flight (2 h)
2. Setup and inspection (3 h)
3. First flight (5 h)
4. Precision flight (7 h)
5. Emergency recovery (5 h)
6. Useful imagery (4 h)
7. Waypoints and mapping outputs (5 h)
8. Next-generation UAV technology (3 h)
9. Real-world mission (4 h)
10. Final flight challenge (2 h)

## Important limitations
- This is an **institutional learning resource**, not a CAAP certificate or regulatory flight authorization.
- Flight rules, airspace permission, and applicable CAAP requirements must be checked before use.
- Hazardous failures (lost link, positioning faults, unexpected movements) must be simulated, not deliberately induced in live aircraft.
- Public material intentionally excludes instructor answer keys.
- The PDFs in this folder are **public learner-facing reflowed editions** produced from course content. Original designed PDFs are retained separately by the course author; the visual layout may differ.
- No application source code is modified by this folder.

## Course material verification
- Verify both downloaded files begin with the bytes `%PDF-` and open in a PDF reader.
- For classroom deployment, review every slide and assessment against current aircraft manuals and CAAP guidance.
- Use signed, version-controlled files for institutional distribution as appropriate.
