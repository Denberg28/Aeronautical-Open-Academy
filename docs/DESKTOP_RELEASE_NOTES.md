# Aeronautical Academy Repository 0.10.0-rc.1 — Instructor access control, registration hardening & rename

23 November 2026 · Windows x64 test candidate / prerelease

## What is included

- **Application rename:** Visible window title, sign-in branding, navigation footer, dialogs, and help documentation updated to **Aeronautical Academy Repository** (`Academy.exe` executable and Electron user-data folder name retained for upgrade continuity).
- **Admin per-subject instructor access control:** New **Subject access** view under Administration (`GET`/`POST /v1/admin/subjects/:id/instructors`, capability `instructor_subject_access: "v1"`). Administrators can assign instructors to subjects as **Read only** or **Editor**, update levels, and **Suspend** or **Activate** instructor subject access immediately (including subject owners). Read-only instructors can view materials, inline PDFs, student progress, and enrollment policy without editing, publishing, scheduling, grading, exporting Excel, viewing quiz answer keys, or downloading files; suspended instructors immediately lose subject visibility.
- **Student default reader with no download capability:** Reinforced end-to-end across `/v1/me` (`student_role_default: "reader"`, `student_download: false`), subject annotations (`access_level: "reader"`), server PDF headers (`Content-Disposition: inline`, `X-Download-Options: noopen`, `X-Robots-Tag: noindex, nofollow`, `?download` blocked with `403` for students and read-only instructors), Electron main-process save/print/context-menu guards, bridge checks, and UI indicators (`Student · Reader`, `Reader (downloads disabled)`, and `View only · downloads disabled` in the PDF reader bar).
- **Login, instructor, and student registration security & workflow:** Strict allow-listed registration payloads, atomic transaction + audit commits for account creation and admin password resets, account creation rate limiting (`30`/window), role-aware Student ID toggle and Show/Hide passphrase toggles in admin Create account, admin **Reset password** and **Edit ID** actions, organization-mode admin-provisioning notice on sign-in, and locked-down **Settings** navigation with passphrase confirmation during forced first-login password rotation.
- **Full 0.6–0.9 feature set preserved:** Standardized desktop UI typography/spacing/contrast, scheduled publishing and due dates (`dates-v1`), shared organization sync (`refresh-v1`), canonical AE 101 template, compact controls, individual activity grading, and dated quiz score Excel exports.

## Installation, compatibility and rollback

Extract the entire Windows x64 ZIP and run `Academy.exe`. Keep all files beside the executable. Local synthetic test accounts remain `admin/admin`, `instructor/instructor`, and `student/student`.

Organization mode pairs with the matching Academy HTTPS API advertising `sync=refresh-v1`, `choice_forms`, `dates-v1`, and `instructor_subject_access=v1` (older compatible servers remain usable with graceful fallback when `instructor_subject_access` is absent). Local demo databases upgrade to Windows schema 13 (`subject_instructors` table with active-editor backfill for existing instructor owners), saving a consistent `academy-before-pc-0.10.sqlite` backup before upgrading from schema `< 13`. Never copy a Windows local database onto the main schema-8 API. Close and back up `local-test-workspace` before upgrading; rollback requires the prior application (`pc-v0.9.0`) and its matching pre-upgrade backup.
