# Windows 0.11.0-rc.1 admin subject folders & left-pane hierarchy checkpoint

Goal: add administrator capability to create folders, drag and drop subjects into folders, and drag and drop folders to move hierarchy in the left navigation pane. Baseline `b23fe29` (`pc-v0.10.0-rc.1`) on `desktop/compact-controls-grading`; branch `feat/pc-admin-subject-folders`; version `0.11.0-rc.1` (Windows local schema 14 with `academy-before-pc-0.11.sqlite` pre-upgrade snapshot; Android app source untouched).

Completed: added idempotent transactional schema v14 migration (`subject_folders` table + nullable `subjects.folder_id`); implemented admin-only `/v1/admin/folders` (GET/POST), `/v1/admin/folders/:id` (PATCH/DELETE with cycle check, 5-level depth guard, sibling resequencing, safe content promotion on delete, and atomic audit logging), and `/v1/admin/subjects/:id/folder` (POST); scoped `GET /v1/subjects` folder visibility so non-admins only see folders containing (or ancestors of) their visible subjects; added left-pane folder hierarchy UI, inline create/rename/delete, isolated subject/folder drag-and-drop (before/inside/after/top-level), `Alt+Arrow` keyboard folder hierarchy shortcuts, and subject-card folder badges.

Verification: host checks (55 server/migration tests including `folders.test.mjs` and v13 → v14 migration, 10 desktop bridge/forms/shared-API tests, all 9 native Electron Playwright UI suites under Xvfb including `folders.mjs`, project checks, npm audit) and Windows CI + paired Android CI on exact final source. Physical Windows 10/11 DPI/accessibility, live organization deployment, real provider sign-in, and code signing remain NOT TESTED.
