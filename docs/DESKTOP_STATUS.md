# Windows 0.10.0-rc.1 instructor access control, registration hardening & rename checkpoint

Goal: add administrator per-subject instructor access control (suspend/activate, read-only vs editor), reinforce student default reader with no download capability, review and harden login/instructor/student registration security and workflow, and rename the PC application to **Aeronautical Academy Repository**. Baseline `7fa2a8a` (`pc-v0.9.0`) on `desktop/compact-controls-grading`; branch `feat/pc-instructor-access-security-rename`; version `0.10.0-rc.1` (Windows local schema 13 with `academy-before-pc-0.10.sqlite` pre-upgrade snapshot; Android app source untouched).

Completed: added schema v13 `subject_instructors` table with active-editor backfill for existing instructor owners; implemented `/v1/admin/subjects/:id/instructors` (GET/POST) and server-enforced read-only/editor/suspended access checks across subjects, items, quizzes/answer keys, learners, eligibility, grading, Excel export, and PDF download blocking; hardened `/v1/admin/accounts` with strict field allow-listing, rate limiting, atomic audited account creation and password resets, and `subject_instructors` cleanup on role change/deletion; added `X-Download-Options: noopen`, `X-Robots-Tag: noindex, nofollow`, main-process context-menu/Ctrl+S/Ctrl+P blocking, bridge defense-in-depth guards, and PDF reader view-only indicator; built admin **Subject access** UI, role-aware Create account with Show/Hide toggle, admin Reset password & Edit Student ID forms, locked-down first-login password rotation with confirmation, organization-mode sign-in hint, and renamed all visible app titles/branding to **Aeronautical Academy Repository**.

Verification: host checks (53 server/migration tests, 10 desktop bridge/forms/shared-API tests, all 8 native Electron Playwright UI suites under Xvfb including `access-control.mjs`, project checks, npm audit) and Windows CI + paired Android CI on exact final source before `pc-v0.10.0-rc.1` prerelease publication. Physical Windows 10/11 DPI/accessibility, live organization deployment, real provider sign-in, and code signing remain NOT TESTED.
