# Windows 0.9.0 UI standardization and stable release checkpoint

Goal: review and standardize the Windows desktop application UI (font sizes, text spacing, paragraph spacing, paddings, contrast, alignment), features, and workflows, then build and publish the owner-authorized stable Windows release `pc-v0.9.0`. Baseline `b0176e0` (`pc-v0.9.0-rc.1`) on `desktop/compact-controls-grading`; branch `release/pc-v0.9.0-ui-polish`; version `0.9.0` (Windows local schema 12 unchanged; Android app source untouched).

Completed: consolidated `desktop/ui/style.css` into authoritative root tokens and single-layer sections (preserving `16 px` / `1.4` / `12 px` reading copy while standardizing controls to `14 px`/`13 px`/`12 px` minimum and WCAG AA muted contrast); fixed rightbar notice hierarchy, collapsed review padding, `.push` action-bar utility, link-field alignment, compact topbar alignment, PDF reader toolbar, schedule dialog spacing, Show/Hide password toggle, `Read PDF` button clarity, blue `Scheduled` badge, `isVisibleEntry` scheduled check, About-this-subject `.reading-copy` wrapper, Discover descriptions, Announcements empty state, Accounts Cancel action, Settings session-card separation, subject-edit pinned-header hiding, learner-view Sync preservation, and reader cleanup on logout/password change; updated `.github/workflows/desktop.yml` to support verified stable release publication without overwriting existing tags.

Verification: host checks (server 50 tests, desktop 10 tests, all 7 native Electron Playwright UI suites under Xvfb, project checks, npm audit) and Windows CI + paired Android CI on exact final source before `pc-v0.9.0` publication. Physical Windows 10/11 DPI/accessibility, live organization deployment, real provider sign-in, and code signing remain NOT TESTED.
