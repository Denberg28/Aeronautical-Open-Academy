# 0.8.0-alpha.1 — subject dragging and minimal interface

Hold the ≡ handle on a subject: the row lifts, follows your finger and moves neighboring rows aside. This adapts HARU’s task interaction to the account subject list using Android RecyclerView/ItemTouchHelper (1.3.2). Measured row heights and stable subject IDs support wrapped text; edge scrolling supports long lists. Finish/cancel/leave saves personal order for that account and organization on this device. Tap a card to open it; ⋮ → Move up/down is the accessible alternative. New subjects append and unavailable subjects disappear. Enrollment, entry order and learner results are unchanged.

Subject and entry + controls now have transparent resting backgrounds. Font hierarchy, medium-weight headings, line spacing, 48 dp button/handle targets, 52 dp text fields, focused outlines, dropdown sizes, 12 dp corners, and even card/form padding are unified. Content is centered up to 760 dp on wide screens. Short navigation transitions respect Android’s disabled-animation setting; refresh has no crossfade. Subject-list position survives returning from a subject and configuration recreation.

Default local test logins remain admin/admin, instructor/instructor and student/student. No backend upgrade or schema change is needed. Personal subject order stays on this installation and does not sync across phones. The existing + → type/text → Done entry workflow and confirmed deletion are retained.

Development test APK. Automated source/core/workflow checks, Android debug/release builds and lint run in CI. Real-phone drag/autoscroll, 200% fonts/TalkBack, keyboard/dropdown layouts and lifecycle transitions remain NOT TESTED; this is not a stable release. Existing debug signing certificates can differ and uninstall clears local test data/preferences. Rollback: retain the preceding APK; no backend/local database migration is introduced by this update.
